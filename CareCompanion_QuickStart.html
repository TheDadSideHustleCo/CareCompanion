Getting Started
🚀 First Time Setup
1
Open the file — double-click carecompanion.html in any browser
2
Accept the disclaimer — check the box, click "I Understand"
3
Enter profile — name, DOB, and primary condition of your loved one
4
Take the tour — 6-step walkthrough fires automatically
5
Follow the checklist — the Dashboard shows 4 recommended first steps
⭐ Four First Steps
1
💊 Medications — add all current meds with dose, frequency, times
2
👥 Care Team — add doctors, nurses, and emergency contacts
3
🚨 Emergency Card — auto-fills from your data, print for the fridge
4
📋 First Log Entry — record today's mood, sleep, appetite, observations
All Sections

  • Check off today's medications

  • Good Days memory strip

  • Name, dose, frequency, timing

  • Mood, sleep, appetite, pain (0–10)

📅 Appointments
  • Auto-sorted by date & time
  • Past / upcoming visual split

  • Prep notes per appointment
👥 Care Team
  • Doctors, nurses, family contacts

  • For rotating caregivers

  • Timestamped by shift
💛 Memory Box
  • Capture precious moments
  • Mood emoji for each memory

  • Beautiful moments surfaced on dashboard

  • Daily caregiver stress check-in (1–10)
